Analysis scripts for studying the tracking performance of the EPIC detector.

The folder **Efficiency Resolution** contains analysis on the efficiencies and the resolution and **StudyOfHits** contains analysis on the SimHits, RecHits and Measurement Hits used during the reconstruction of charged particles. 

For the folder **StudyOfHits**, the path for the input .edm4eic.root file must be edited within the .C file.
